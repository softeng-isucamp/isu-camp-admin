# ISU-CAMP Campus Locations

This glossary defines the places and spatial terms shared by the Locations directory and Map Editor.

## Places

**Campus Location**:
A named place managed in the campus directory, such as a building, facility, room, office, laboratory, or restroom.

**Building Footprint**:
The mapped outline of a building. It describes the building's physical extent and is distinct from the building's directory details.

**Indoor Location**:
A room, office, laboratory, or restroom associated with a parent building and, optionally, a floor level.

**Floor Level**:
A named level within a building used to organize its indoor locations.

**Indoor Location Marker**:
An optional map point identifying where an indoor location is within its parent building.
